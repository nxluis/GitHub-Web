# Sistema de Gestión de Pedidos y Mesas - Restaurante

Aplicación web para gestionar pedidos y visualizar el estado de las mesas de un restaurante.

## Descripción
Esta herramienta permite registrar los pedidos de cada mesa, asignar productos y ver de forma inmediata qué mesas están ocupadas, libres o en servicio. Mejora la organización y la comunicación entre el personal.

## Características principales
- Visualización de mesas: Estado claro de cada mesa (libre / ocupada / en servicio)
- Registro de pedidos: Asignar productos, cantidades y observaciones
- Cálculo automático: Suma de totales y detalles por mesa
- Actualización en tiempo real: Los cambios se ven sin recargar la página
- Panel intuitivo: Interfaz sencilla para uso rápido

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
