# 🍴 Sistema de Gestión de Pedidos y Mesas — Restaurante

> Aplicación web para gestionar pedidos y visualizar en tiempo real el estado de las mesas de un restaurante.

## 📖 Descripción
Esta herramienta permite al personal del restaurante registrar los pedidos de cada mesa, asignar productos y ver de forma inmediata qué mesas están ocupadas, libres o en proceso de atención. Optimiza la comunicación entre el área de atención y cocina, reduciendo errores y mejorando la experiencia del cliente.

## ✨ Características principales
- 🪑 **Visualización de mesas**: Estado claro y diferenciado de cada mesa (libre / ocupada / en servicio).
- 📝 **Registro de pedidos**: Asignar productos, cantidades y observaciones a cada mesa.
- 💰 **Cálculo automático**: Suma de totales y detalles del consumo por mesa.
- 🔄 **Actualización en tiempo real**: Los cambios se reflejan sin recargar la página.
- 📊 **Panel intuitivo**: Interfaz sencilla, diseñada para uso rápido por el personal.
